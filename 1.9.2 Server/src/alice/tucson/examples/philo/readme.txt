Philosophers
------------

This is the classic Dining Philosophers application.

There is a society of 5 (philosopher) agents (in part Prolog and Java agents)
which eat at the same table sharing chops.
The social task implies eating and sharing resources concurrently and need
coordination to avoid deadlock and exchange information.
The philosopher society is designed and build upon the  default tuple
centre, which is programmed to enforce the coordination activity related to
the social task.

Be sure to have the alice/tucson/examples package accessible from your path.

To execute the application:

        java -cp .;tucson.jar alice.tucson.examples.philo.PhiloRun
